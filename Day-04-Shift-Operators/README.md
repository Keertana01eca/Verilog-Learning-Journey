# Day 4 – Shift Operators

## Topic
Behavioral Modeling

## Description
Implemented Shift Operators in Verilog using Behavioral Modeling and verified their functionality through simulation using a custom testbench in QuestaSim.

---

## Shift Operators Covered

- Logical Right Shift (>>)
- Logical Left Shift (<<)
- Arithmetic Right Shift (>>>)
- Arithmetic Left Shift (<<<)

---

## Key Learning

- Learned how logical shift operators move bits and fill empty positions with `0`.
- Understood that arithmetic right shift (`>>>`) preserves the sign bit when operating on signed data.
- Observed that for unsigned inputs, `>>` and `>>>` may produce the same result.
- Verified the behavior of each operator using simulation waveforms.
