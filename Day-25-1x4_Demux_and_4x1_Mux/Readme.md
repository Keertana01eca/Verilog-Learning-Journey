# Day 25 – 1×4 Demux and 4×1 Mux Combined Circuit

## 📌 100 Days Verilog Challenge

On Day 25 of my 100 Days Verilog Challenge, I implemented a **combined circuit consisting of a 1×4 Demultiplexer and a 4×1 Multiplexer**.

## 🔹 Design

The circuit contains:

### 1×4 Demultiplexer

- 1 Data Input
- 2 Select Lines
- 4 Outputs

The input data is routed to one of the four outputs based on the select lines.

### 4×1 Multiplexer

- 4 Data Inputs
- 2 Select Lines
- 1 Output

One of the four inputs is selected and routed to the output based on the select lines.
